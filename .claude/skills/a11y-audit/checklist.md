# Accessibility checklist

Per module. Evidence, not checkmarks.

```
Module: ..................

## TalkBack
- [ ] Every interactive element labelled
- [ ] Labels read state before name ("On, filter, 1700 kelvin")
- [ ] Decorative elements excluded from the tree
- [ ] Warmth and brightness exposed as seekbars, 10 percent increments
- [ ] Volume keys adjust the focused seekbar
- [ ] Reading order sensible; donation entry behind both real controls

## Font scaling
- [ ] 200 percent preview exists for every screen
- [ ] Nothing clips, truncates, or overlaps at 200 percent
- [ ] The 96 px numeral caps at 1.3x and stays on one line
- [ ] Touch targets at least 44 dp, 56 dp for dark-use controls
- [ ] Arc anchors carry 56 dp of invisible padding

## Contrast
- [ ] Body text at or above 4.6:1 at the OFF/DAY column
- [ ] Body text at or above 4.6:1 at 1700 K
- [ ] Large numerals near 3.2:1, deliberately, not raised
- [ ] No element above 80 percent luminance except the panic strip
- [ ] text/hi never exceeds #E9ECEE

## Colour is not the only signal
- [ ] Every colour-carrying element carries a monogram or a spec
- [ ] Migraine preset identifiable greyscaled
- [ ] Enabled and disabled differ by more than hue

## Action pairs
- [ ] Paired actions share height, radius, fill, border, font, weight, colour
- [ ] Fifty-fifty width
- [ ] Nothing ghosted, nothing default-focused
- [ ] Decline is a full-size button, not a text link
- [ ] No amount preselected or marked popular

## Nothing unasked
- [ ] No dialog, toast, or snackbar the user did not cause
- [ ] No animation that repeats after first view
```
